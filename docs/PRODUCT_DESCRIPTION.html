🌿 Plasma Bonsai Assistant

A native, lightweight, and 100% private AI assistant widget for KDE Plasma 6. It connects directly to your local Ollama instance to provide fast streaming chat, desktop vision, and deep KDE system integration—right from your panel or desktop.

✨ Key Features

  • 🔒 100% Local & Private: Connects directly to Ollama (http://localhost:11434). Zero telemetry, zero tracking, no cloud dependencies or API keys.
  • ⚡ Standalone & Daemonless: Runs purely in user space. No heavy background daemon consuming RAM 24/7.
  • 🎨 Native Qt6 & Kirigami UI: Real-time token streaming with animated typing indicator, rich Markdown rendering, quick copy button, and Ollama model selector.
  • 📸 Multimodal Desktop Vision: Integrated screenshot tool via Spectacle to analyze windows, code errors, or graphics using the vision model (bonsai-2:latest).
  • 🛠️ System Control & Actions (Natural Language Tool Calling):
    • Screen Brightness: Adjust or set exact percentage ("Set brightness to 60%").
    • Audio Control: Adjust volume or mute/unmute audio.
    • Wallpaper: Change Plasma wallpaper on demand.
    • Application Launcher: Open terminal, browser, Dolphin, text editor, etc.
    • Window Management: Toggle desktop view, overview, or 50/50 window tiling.
    • File Operations: Safe folder creation in $HOME and fast document/file search with native KDE Baloo ("Find invoice and open it").
    • Timers: Native KDE notifications with timers ("Set a 10 min timer").
    • Security: Lock desktop session instantly.
  • ⚙️ Integrated Settings: Configure custom Ollama URL, preferred language (Auto / English / Spanish), and custom System Prompt directly in the widget.

🚀 Requirements

  1. KDE Plasma 6
  2. Python 3 (included in all modern Linux distributions)
  3. Ollama running locally: 
    curl -fsSL https://ollama.ai/install.sh | sh
ollama pull bonsai-2:latest
